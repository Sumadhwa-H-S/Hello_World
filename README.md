---

## Project Description

This project demonstrates the creation of a basic Android application using Kotlin and XML.

The application consists of a single activity (`MainActivity`) that loads an XML layout (`activity_main.xml`). A TextView is placed at the center of the screen using ConstraintLayout and displays the following message:

> **Hello I am Sumadhwa H S**

The project helps in understanding the basic Android application structure, user interface design, and project deployment using GitHub.
